Aviso de privacidad

Última actualización: 31 de octubre de 2026

Lo que escribes en el simulador

Los cálculos se hacen en tu navegador. Los valores que escribes se guardan solo en el almacenamiento local de tu navegador (localStorage), para que sigan ahí cuando vuelvas. No se envían a ningún servidor y puedes borrarlos desde los ajustes de tu navegador.

Cuentas y cookies

El sitio no tiene cuentas ni formularios de registro, y no usa cookies propias, herramientas de analítica ni publicidad.

Registros técnicos

El sitio se sirve con GitHub Pages y Cloudflare. Como cualquier servicio web, pueden registrar datos técnicos de cada visita, como la dirección IP y el tipo de navegador, para operar el servicio y protegerlo. Cloudflare también puede usar cookies técnicas de seguridad. El tratamiento de esos datos se rige por sus propias políticas de privacidad: GitHub y Cloudflare.

Enlaces y reportes

Si abres un reporte en GitHub para contactarnos, lo que escribas será público y quedará sujeto a las condiciones de GitHub. No incluyas datos personales ni financieros.

Cambios

Si el sitio empieza a usar analítica o publicidad, este aviso se actualizará antes de activarlas.

Contacto

Escríbenos en los reportes del proyecto en GitHub.
